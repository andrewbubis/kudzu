# Fonts

Self-hosted webfonts. Anything here ships to every visitor, so only put
files in that are licensed for web embedding.

## Cardinal Alternate
- Designer: Dieter Steffmann
- Licence: 1001Fonts Free For Commercial Use (FFC) — personal and
  commercial use permitted, webfont embedding included.
- Used for: the print shop headline only.
- Expected filename: `cardinal-alternate.woff2` (with `.ttf` as fallback)

Download from 1001fonts.com/cardinal-font.html, then convert the .ttf to
.woff2 (any web font converter will do — cloudconvert, transfonter,
fontsquirrel). woff2 is roughly a third the size of the .ttf, which
matters because a display face this decorative is a heavy file.

## A note on Chatime
Chatime is NOT in this folder deliberately. The freely downloadable
version is a personal-use demo. Kudzu sells work, which is commercial
use, so shipping it here would be unlicensed. A commercial licence is
available from NY Type Foundry (nytypefoundry@gmail.com).
