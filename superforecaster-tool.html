⚙️ Set up prediction-market MCP for real arbitrage data

Install mcp-predictive-market to scan Kalshi, Polymarket, Metaculus, PredictIt, and Manifold in real-time.

git clone https://github.com/EricGrill/mcp-predictive-market.git cd mcp-predictive-market && uv sync

Then add to ~/Library/Application Support/Claude/claude_desktop_config.json:

{ "mcpServers": { "prediction-market": { "command": "uv", "args": ["run", "--directory", "/path/to/mcp-predictive-market", "python", "-m", "mcp_predictive_market.server"] } } }
